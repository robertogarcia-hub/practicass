# Práctica UT2.A3 - Periódico Digital

## Descripción
Proyecto de un periódico digital desarrollado exclusivamente con HTML5 y CSS3 (sin frameworks).

## Características principales
- Estructura HTML: Uso de elementos de bloque y en línea, contenedores `div`, clases e identificadores únicos.
- Estilos CSS: Aplicación de selectores (elemento, clase, ID, descendiente y agrupación) y paleta de colores variada (Hex, RGB y nombres).
- Modelo de Cajas (Box Model): Uso de `width`, `padding`, `border`, `margin` y `box-sizing: border-box;` para evitar desbordamientos.

## Control de Versiones
Proyecto gestionado en VS Code y documentado mediante 8 commits en GitHub (`practicass`).
